Confidentialité

Cette page couvre mes projets qui renvoient ici : mes sites web, mes extensions VS Code (AnyaPDF, AnyaXML, AnyaCSV, AnyaJSON) et mon paquet npm (strip-accents).

Traduction : fournie pour plus de commodité. En cas de divergence, la version anglaise fait foi.

En bref

Mes extensions traitent vos fichiers localement dans VS Code. Elles ne m’envoient ni le contenu de vos documents ni de données d’utilisation. Les aperçus et vérifications de gros fichiers lisent directement depuis le disque. Les extensions n’ont ni comptes, ni publicités, ni télémétrie qui me soit envoyée.

  • tourne en local
  • aucune télémétrie vers moi
  • aucun compte
  • aucune publicité

01par projet

  • strip-accents

    npm

    S’exécute entièrement dans votre propre code. Aucun script d’installation, et aucune donnée collectée ni envoyée.

  • AnyaXML

    VS Code

    Formate et minifie les fichiers localement, à l’aide d’un dossier temporaire supprimé après le traitement. Les aperçus et la validation des gros fichiers lisent directement depuis le disque. Les exports Excel sont enregistrés à l’emplacement de votre choix.

  • AnyaCSV

    VS Code

    Mémorise les documents activés et les choix de délimiteur dans le stockage de VS Code. Les aperçus et la vérification des gros fichiers lisent le disque localement. Son diagnostic de colorisation n’enregistre que le temps écoulé dans le journal local de l’hôte d’extensions, sans nom de fichier ni contenu ; AnyaCSV ne m’envoie pas cette entrée. Les exports Excel sont enregistrés à l’emplacement de votre choix.

  • AnyaJSON

    VS Code

    Ne conserve pas le contenu des documents dans le stockage de l’extension. Les aperçus et la validation des gros fichiers lisent localement les fichiers enregistrés sur le disque. Les exports Excel sont enregistrés à l’emplacement de votre choix.

  • AnyaPDF

    VS Code

    Ouvre les PDF dans une webview locale de VS Code et mémorise vos réglages de zoom et d’ajustement à la largeur dans le stockage propre à VS Code.

Remarque : VS Code peut lui-même collecter de la télémétrie selon vos paramètres VS Code. Celle-ci relève de Microsoft, pas de moi.

02ce site web

Ce site web (sanyam.dev) mémorise votre thème clair/sombre dans votre navigateur. Mon hébergeur peut journaliser des données techniques de requêtes pour faire fonctionner et protéger le site. Aucune mesure d’audience ni publicité sur cette page.
