Small, focused tools I build and maintain in the open. They run locally, collect nothing, and do one job well.

01npm package

  • strip-accents

    Node.js

    Removes accents and diacritics from Latin letters, converting them to plain ASCII. Other scripts are left unchanged. No dependencies, no install scripts.

    npm i strip-accents

02VS Code extensions

  • AnyaXML

    XML

    Format, minify and validate XML, and preview it as a filterable table with Excel export. Streams multi-gigabyte files straight from disk.

    marketplace↗ source↗

  • AnyaCSV

    CSV · TSV

    Delimiter-aware editing for CSV and friends: per-column colors, hover details, lint for malformed rows, and a table preview with Excel export.

    marketplace↗ source↗

  • AnyaJSON

    JSON

    Format, minify and lint JSON without touching key order, number spellings or escapes. Preview record arrays as a table and export to Excel.

    marketplace↗ source↗

03Chrome extension

  • QRious

    Chrome · Edge · Brave

    One click makes a QR code for the page you’re on. Copy or download a print-size PNG, or right-click any link to get its code. Works offline; the URL never leaves your browser.

    1. Download the ZIP and unzip it.
    2. Open chrome://extensions and turn on Developer mode.
    3. Click Load unpacked and pick the unzipped folder.
