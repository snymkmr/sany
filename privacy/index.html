Privacy

This page covers my projects that link here: my websites, my VS Code extensions (AnyaPDF, AnyaXML, AnyaCSV, AnyaJSON), and my npm package (strip-accents).

The short version

My extensions process your files locally in VS Code. They do not send your document contents or usage data to me. Large-file previews and checks read files directly from disk. The extensions have no accounts, ads, or telemetry that they send to me.

  • runs locally
  • no telemetry sent to me
  • no accounts
  • no ads

01per project

  • strip-accents

    npm

    Runs entirely in your own code. It has no install scripts and does not collect or send any data.

  • AnyaXML

    VS Code

    Formats and minifies files locally using a temporary folder that is deleted after processing. Large-file previews and validation read directly from disk. Excel exports are written to a location you choose.

  • AnyaCSV

    VS Code

    Remembers enabled documents and delimiter choices in VS Code storage. Large-file previews and lint read from disk locally. Its colorization diagnostic records only elapsed time in the local extension-host log, without a file name or contents; AnyaCSV does not send this entry to me. Excel exports are written to a location you choose.

  • AnyaJSON

    VS Code

    Does not keep document contents in extension storage. Large-file previews and validation read saved files locally from disk. Excel exports are written to a location you choose.

  • AnyaPDF

    VS Code

    Opens PDFs in a local VS Code webview and remembers your zoom and fit-to-width settings in VS Code's own storage.

Note: VS Code itself may collect telemetry based on your VS Code settings. That is Microsoft's, not mine.

02this website

This website (sanyam.dev) remembers your light/dark theme in your browser. It loads fonts from Google Fonts, so Google may see technical info like your IP address when your browser fetches them. My hosting provider may log technical request data to run and protect the site. No analytics or advertising on this page.
