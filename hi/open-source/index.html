//ओपन सोर्स

जो मैंने शिप किया

छोटे, एक काम पर केंद्रित टूल, जो खुले में बनाए और संभाले जाते हैं। ये लोकल चलते हैं, कुछ भी इकट्ठा नहीं करते, और अपना एक काम बढ़िया करते हैं।

01npm पैकेज

  • strip-accents

    Node.js

    लैटिन अक्षरों से एक्सेंट और डायक्रिटिक हटाकर उन्हें सादे ASCII में बदलता है। दूसरी लिपियों को नहीं छेड़ता। न कोई डिपेंडेंसी, न कोई इंस्टॉल स्क्रिप्ट।

    npm i strip-accents
    npm↗ सोर्स↗

02VS Code एक्सटेंशन

  • AnyaXML

    XML

    XML को फ़ॉर्मैट, मिनिफ़ाई और वैलिडेट करें, और उसे फ़िल्टर होने वाली टेबल के रूप में देखें, Excel एक्सपोर्ट के साथ। कई गीगाबाइट की फ़ाइलें सीधे डिस्क से स्ट्रीम करता है।

    मार्केटप्लेस↗ सोर्स↗

  • AnyaCSV

    CSV · TSV

    CSV और उसके जैसे फ़ॉर्मैट के लिए डिलिमिटर समझने वाली एडिटिंग: हर कॉलम का अलग रंग, होवर पर जानकारी, गड़बड़ पंक्तियों की जाँच, और Excel एक्सपोर्ट के साथ टेबल प्रीव्यू।

    मार्केटप्लेस↗ सोर्स↗

  • AnyaJSON

    JSON

    JSON को फ़ॉर्मैट, मिनिफ़ाई और लिंट करें, बिना कीज़ का क्रम, नंबरों की लिखावट या एस्केप बदले। रिकॉर्ड की ऐरे को टेबल में देखें और Excel में एक्सपोर्ट करें।

    मार्केटप्लेस↗ सोर्स↗

  • AnyaPDF

    PDF

    VS Code के अंदर ही PDF पढ़ें। ज़रूरत पड़ने पर पेज रेंडरिंग, टेक्स्ट चुनना और खोजना, ज़ूम और चौड़ाई के हिसाब से फ़िट, और आउटलाइन से नेविगेशन।

    मार्केटप्लेस↗ सोर्स↗

03Chrome एक्सटेंशन

  • QRious

    Chrome · Edge · Brave

    एक क्लिक में, खुले हुए पेज का QR कोड। उसे कॉपी करें या प्रिंट-साइज़ PNG डाउनलोड करें, या किसी भी लिंक पर राइट-क्लिक करके उसका कोड पाएँ। ऑफ़लाइन चलता है; URL आपके ब्राउज़र से बाहर नहीं जाता।

    1. ZIP डाउनलोड करके अनज़िप करें।
    2. chrome://extensions खोलें और Developer mode चालू करें।
    3. Load unpacked पर क्लिक करें और अनज़िप किया हुआ फ़ोल्डर चुनें।
    zip डाउनलोड करें↓ सोर्स↗
