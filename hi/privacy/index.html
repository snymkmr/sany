प्राइवेसी

यह पेज मेरे उन प्रोजेक्ट्स पर लागू होता है जो यहाँ लिंक करते हैं: मेरी वेबसाइटें, मेरे VS Code एक्सटेंशन (AnyaPDF, AnyaXML, AnyaCSV, AnyaJSON), और मेरा npm पैकेज (strip-accents)।

अनुवाद: यह सुविधा के लिए है। किसी अंतर की स्थिति में अंग्रेज़ी संस्करण ही मान्य होगा।

संक्षेप में

मेरे एक्सटेंशन आपकी फ़ाइलों को VS Code में लोकल ही प्रोसेस करते हैं। वे आपके दस्तावेज़ों की सामग्री या इस्तेमाल का डेटा मुझे नहीं भेजते। बड़ी फ़ाइलों के प्रीव्यू और जाँच सीधे डिस्क से फ़ाइलें पढ़ते हैं। इन एक्सटेंशन में न अकाउंट हैं, न विज्ञापन, न ऐसी टेलीमेट्री जो मुझे भेजी जाए।

  • लोकल चलता है
  • मुझे कोई टेलीमेट्री नहीं
  • कोई अकाउंट नहीं
  • कोई विज्ञापन नहीं

01हर प्रोजेक्ट

  • strip-accents

    npm

    पूरी तरह आपके अपने कोड में चलता है। इसमें कोई इंस्टॉल स्क्रिप्ट नहीं है, और यह न कोई डेटा इकट्ठा करता है, न भेजता है।

  • AnyaXML

    VS Code

    फ़ाइलों को एक अस्थायी फ़ोल्डर की मदद से लोकल ही फ़ॉर्मैट और मिनिफ़ाई करता है; प्रोसेसिंग के बाद वह फ़ोल्डर हटा दिया जाता है। बड़ी फ़ाइलों के प्रीव्यू और वैलिडेशन सीधे डिस्क से पढ़ते हैं। Excel एक्सपोर्ट आपकी चुनी हुई जगह पर सेव होते हैं।

  • AnyaCSV

    VS Code

    चालू किए गए दस्तावेज़ और डिलिमिटर की पसंद VS Code स्टोरेज में याद रखता है। बड़ी फ़ाइलों के प्रीव्यू और लिंट डिस्क से लोकल ही पढ़ते हैं। इसका कलराइज़ेशन डायग्नॉस्टिक लोकल extension-host लॉग में सिर्फ़ बीता हुआ समय दर्ज करता है, बिना फ़ाइल के नाम या सामग्री के; AnyaCSV यह एंट्री मुझे नहीं भेजता। Excel एक्सपोर्ट आपकी चुनी हुई जगह पर सेव होते हैं।

  • AnyaJSON

    VS Code

    दस्तावेज़ों की सामग्री एक्सटेंशन स्टोरेज में नहीं रखता। बड़ी फ़ाइलों के प्रीव्यू और वैलिडेशन सेव की गई फ़ाइलों को डिस्क से लोकल ही पढ़ते हैं। Excel एक्सपोर्ट आपकी चुनी हुई जगह पर सेव होते हैं।

  • AnyaPDF

    VS Code

    PDF को VS Code के लोकल वेबव्यू में खोलता है और आपकी ज़ूम व चौड़ाई-फ़िट सेटिंग VS Code के अपने स्टोरेज में याद रखता है।

ध्यान दें: आपकी VS Code सेटिंग के हिसाब से VS Code ख़ुद टेलीमेट्री इकट्ठा कर सकता है। वह Microsoft की है, मेरी नहीं।

02यह वेबसाइट

यह वेबसाइट (sanyam.dev) आपके ब्राउज़र में आपकी लाइट/डार्क थीम याद रखती है। यह फ़ॉन्ट Google Fonts से लोड करती है, इसलिए जब आपका ब्राउज़र उन्हें लाता है तो Google आपका IP पता जैसी तकनीकी जानकारी देख सकता है। मेरा होस्टिंग प्रदाता साइट चलाने और सुरक्षित रखने के लिए तकनीकी अनुरोध डेटा लॉग कर सकता है। इस पेज पर कोई एनालिटिक्स या विज्ञापन नहीं है।
